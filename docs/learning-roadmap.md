# Buyvora 学习与开发路线

这份路线把完整电商 Agent 拆成可以独立理解、独立测试、独立提交的小阶段。

## 阶段 0：工程基础（当前）

学习 Python 项目结构、FastAPI、虚拟环境、自动化测试，以及 Git 的基本提交流程。

## 阶段 1：购物对话接口

增加会话请求模型和 `POST /commerce/chat`，先用确定性的回复验证前后端数据流。学习 API schema、请求校验和错误处理。

## 阶段 2：商品领域模型

建立商品、SKU、金额和库存等基础类型，并用内存商品仓储保存种子数据。学习领域模型与接口分离。

## 阶段 3：第一个可用 Agent

接入 OpenAI 兼容模型，增加商品搜索工具，让 Agent 能理解购物需求并调用搜索能力。学习提示词、工具调用和环境变量管理。

## 阶段 4：检索与推荐

从关键词搜索逐步升级到向量检索、重排序和结构化过滤。学习 RAG、召回质量和评测集设计。

## 阶段 5：记忆与价格

增加用户偏好记忆、汇率、运费和税费计算。学习状态管理、持久化和业务规则测试。

## 阶段 6：订单与安全边界

增加创建、查询和取消订单，并为写操作增加确认、幂等和权限边界。学习 Agent 不应擅自执行高风险操作。

## 阶段 7：可视化与部署

增加 React 对话界面、事件流、Docker 和基础观测能力，最终形成可展示的简历项目。

每个阶段都遵循：先理解概念 → 写最小实现 → 写测试 → 本地验证 → 提交 Git → 推送 GitHub。
